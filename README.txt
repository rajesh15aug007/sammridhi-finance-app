SAMMRIDHI FINANCE — FINAL TRIAL
================================
This is a browser-only trial build. Open index.html to start the trial.
Demo data is stored in the browser's localStorage.

Included:
Dashboard, Leads, Applications, Connectors, Lenders, KYC/document records,
Follow-ups, MIS, team, commission calculation, CSV export and reset.

This trial is NOT a production backend and must not be used for real customer
KYC/financial data. The production build needs a server, PostgreSQL, HTTPS,
encrypted document storage, backups, authentication/MFA, audit controls and
notification integrations.

For production deployment, use a supported Node.js LTS release. The official
Node.js download page currently lists the 24.x line as LTS.
